ROBOT WEB - MODE D'EMPLOI
=========================
Le robot refait tout seul une tache que vous lui avez montree UNE fois dans le
navigateur. Vous la relancez quand vous voulez, autant de fois que vous voulez :
elle n'est jamais « deja faite ».

Pas besoin d'Excel. Un Excel ne sert que si vous voulez repeter la tache sur une
liste (une ligne = une execution, par exemple un export par contrat) : partie 6.

Vous n'avez rien a programmer. Vous montrez, il note, il rejoue.


=====================================================================
 1. OUVRIR LE ROBOT
=====================================================================
MAC
   Ouvrez le Terminal (Cmd+Espace, tapez "terminal", Entree), puis :
       cd ~/Desktop/robot-web
       ./robot.command
WINDOWS
   Ouvrez le dossier robot-web dans l'explorateur, cliquez dans la barre
   d'adresse, tapez  cmd  puis Entree, puis :
       robot

Un menu s'affiche :
   1. Enregistrer une nouvelle tache (vous la montrez au robot)
   2. Lancer une tache enregistree
   3. Voir mes taches
   4. Supprimer une tache
   5. Creer un fichier Excel de pilotage (facultatif)
   6. M'entrainer sur la fausse base de demonstration
   7. Verifier que tout fonctionne
   0. Quitter
Tapez le chiffre, Entree. C'est tout ce qu'il y a a retenir.


=====================================================================
 2. MONTRER LA TACHE AU ROBOT (choix 1, une seule fois par tache)
=====================================================================
Le menu demande :
   - l'adresse de l'outil (celle qui s'affiche dans la barre du navigateur) ;
   - un nom pour la tache (ex : "export plans hdk") ;
   - « Avec un fichier Excel ? » : Entree (= non), sauf besoin d'une liste.

Un navigateur s'ouvre, avec un BANDEAU ROUGE en bas a gauche.
   1. Faites votre tache normalement, UNE SEULE FOIS, du debut a la fin.
      Connectez-vous, cliquez, filtrez, exportez : comme d'habitude.
   2. Quand c'est termine, cliquez sur le bandeau rouge.
      Si le bandeau gene un bouton de l'outil, ou ne reagit pas : revenez au
      Terminal et appuyez sur Entree, cela termine aussi l'enregistrement.

Le robot affiche la liste de ce qu'il a note, puis pose ses questions.
Entree partout convient tres bien :
   - "Etapes a retirer" : Entree si tout est bon. Sinon, les numeros a jeter.
   - "Les premieres etapes ressemblent a une connexion, la faire une seule fois
     au debut ?" : o. Elle ne sera refaite que si le site la redemande.
   - Dossier et nom des fichiers telecharges : le nom propose contient
     {{horodatage}} (la date et l'heure) : chaque lancement donne un nouveau
     fichier, le precedent n'est jamais ecrase.
   - Pause au debut pour verifier la connexion : o (le plus sur).
   - Capture d'ecran a la fin : comme vous voulez.

Le robot ecrit alors un fichier .yaml dans le dossier robot-web\taches\ : c'est la
tache. C'est un fichier texte lisible, que vous pouvez ouvrir et modifier.
Le navigateur du robot garde sa connexion d'une fois sur l'autre (dossier
taches\profils\), comme votre Chrome habituel.

MOT DE PASSE : il n'est jamais ecrit dans le fichier, ni affiche dans la console.
Le robot met a la place {{mot_de_passe}} et vous le demande au lancement (la frappe
ne s'affiche pas). Vous pouvez aussi le donner dans la commande avec
--var mot_de_passe=VOTRE_MOT_DE_PASSE.
CODE RECU PAR SMS : le robot ne peut pas l'inventer. Il met une pause a cet
endroit : vous tapez le code dans le navigateur, puis Entree dans le Terminal.


=====================================================================
 3. RELANCER LA TACHE (choix 2, quand vous voulez)
=====================================================================
Choix 2, puis le numero de la tache. Le robot rejoue tous vos gestes.
A la fin, la console affiche :
       Tache reussie. Vous pouvez la relancer quand vous voulez.
Pour la refaire : choix 2 a nouveau. Aujourd'hui, demain, dans un mois.

Si c'est une ERREUR : la console dit quel geste a bloque, et une photo de
l'ecran au moment du probleme est rangee dans taches/captures/erreurs/.


=====================================================================
 4. OU SONT MES FICHIERS ?
=====================================================================
   - les fichiers exportes : robot-web\exports\ (un par lancement, date et heure
     dans le nom). Depuis le dossier robot-web :  explorer exports
   - les taches : robot-web\taches\
   - les captures d'ecran : robot-web\taches\captures\


=====================================================================
 5. TOUT RECOMMENCER A ZERO
=====================================================================
Voir GUIDE_VRAI_SITE.txt, partie A : on efface le dossier du robot et on
reinstalle. Vos fichiers a vous et votre Chrome habituel ne sont pas touches.


=====================================================================
 6. FACULTATIF : LA MEME TACHE SUR UNE LISTE (EXCEL)
=====================================================================
Utile seulement si la tache doit etre faite pour plusieurs valeurs, par exemple
un export pour chaque contrat. Une ligne = une execution :
       Contrat
       HDK
       QRS
       LMN
Choix 5 du menu cree ce fichier. Puis choix 1, et « o » a « Avec un fichier
Excel ? ». Faites la tache avec la valeur de la PREMIERE ligne ; le robot
demande ensuite quelle colonne donne chaque valeur saisie.
Au lancement (choix 2), « 1 » fait une seule ligne pour tester, « 2 » toutes.
Chaque lancement refait toutes les lignes ; l'Excel note pour chacune OK ou
ERREUR, l'heure et le message.
REGLE IMPORTANTE : fermez le fichier Excel avant de lancer le robot.


=====================================================================
 7. QUAND CA NE MARCHE PAS
=====================================================================
 - Lisez la ligne ERREUR de la console : elle nomme l'etape et la cause.
 - Regardez la capture dans taches/captures/erreurs/ : l'ecran au moment du probleme.
 - "delai depasse : element introuvable" : l'outil a change, ou la page etait
   plus lente que d'habitude. Refaites un enregistrement (choix 1), ou
   augmentez delai_max dans le fichier .yaml.
 - "le fichier est ouvert dans Excel" : fermez-le, le robot reprend tout seul.
 - Si vous ne vous en sortez pas : envoyez a Claude la ligne d'erreur affichee
   par la console. Aucune donnee de votre entreprise
   n'est necessaire : ni capture, ni fichier, ni nom de contrat.


=====================================================================
 8. PLUSIEURS TACHES
=====================================================================
Vous pouvez enregistrer autant de taches que vous voulez : une par type de
travail (export par contrat, mise a jour d'indice, depot de document...).
   - Choix 3 : la liste de vos taches.
   - Choix 4 : en retirer une (le fichier part dans corbeille/, rien n'est perdu).
   - Rate ? Refaites simplement un enregistrement, l'ancien est conserve avec la
     date dans son nom.


=====================================================================
 9. REGLES D'OR
=====================================================================
 1. Faire le premier essai sur une tache sans risque (pas de suppression).
 2. Regarder l'ecran la premiere fois que le robot rejoue une tache.
 3. Avec un Excel : toujours fermer le fichier avant de lancer.
 4. Le robot ne fait QUE ce que vous lui avez montre. Il n'invente rien.
    S'il ne trouve pas un bouton, il s'arrete et le dit.
 5. Rien ne sort de votre poste : ni vos donnees, ni vos mots de passe,
    ni les pages visitees.


=====================================================================
 10. QUELQUES COMMANDES, SI VOUS PREFEREZ TAPER
=====================================================================
(Mac : ./robot.command ...   Windows : robot ...)

   robot                                      le menu
   robot enregistrer ADRESSE --nom "ma tache"
   robot lancer taches\ma_tache.yaml          rejoue la tache (autant de fois que voulu)
   robot lancer taches\ma_tache.yaml --limite 1   (avec Excel) une seule ligne
   robot lancer ma_tache.yaml --var mot_de_passe=MONMOTDEPASSE
   robot simuler ma_tache.yaml                montre les etapes sans rien faire
   robot scenarios                            la liste des taches
   robot base-demo                            la fausse base d'entrainement
