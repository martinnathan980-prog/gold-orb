PRISE EN MAIN DU ROBOT - ETAPE 1
================================
On repart de zero, en simple. Un seul fichier : prise_en_main.txt
Il montre, une chose a la fois, ce que le robot sait faire sur VOTRE ordinateur,
et il affiche OK ou ECHEC pour chaque chose. Duree : 10 minutes.

Il ne modifie RIEN dans vos outils. Il cree seulement un dossier « Robot - essai »
sur votre Bureau (vous pourrez le supprimer). Sur le portail, il ne clique que sur
ce que VOUS lui demandez, apres votre accord, et il refuse Supprimer, Enregistrer,
Valider, Dupliquer, Nouveau, OK...


1. PREPARER (1 minute)
----------------------
   a. Enregistrez prise_en_main.txt dans votre dossier Telechargements.
   b. Ouvrez le dossier Telechargements.
   c. Cliquez dans la barre d'adresse du dossier (en haut, la ou il y a ecrit
      « Telechargements »), effacez, tapez  cmd  puis Entree.
      Une fenetre noire s'ouvre.
   d. Dans la fenetre noire, VOUS TAPEZ :
          python prise_en_main.txt
      puis Entree.
      (Si « python » n'est pas reconnu, tapez :  py prise_en_main.txt )


2. CE QUI VA SE PASSER
----------------------
Avant chaque etape, le robot explique ce qu'il va faire et attend que vous
appuyiez sur Entree dans la fenetre noire. Ensuite, il vous demande si vous avez
vu la chose se faire : repondez  o  (oui) ou  n  (non), puis Entree.

   Etape 1  Python fonctionne                      (rien a faire)
   Etape 2  Il cree un dossier sur le Bureau et l'ouvre
   Etape 3  Il ouvre SON fichier « essai_clavier » dans le Bloc-notes et
            ECRIT TOUT SEUL dedans (jamais dans un autre document)
            -> ne touchez ni au clavier ni a la souris pendant 10 secondes
   Etape 4  Il BOUGE LA SOURIS tout seul et clique dans ce Bloc-notes
            -> ne touchez pas a la souris pendant 5 secondes
   Il vous demande l'adresse de votre portail : dans votre Chrome, allez sur
   l'ACCUEIL du portail, cliquez dans la barre d'adresse, Ctrl+C. Revenez dans
   la fenetre noire, Ctrl+V pour coller, puis Entree.
   Etape 5  Il ouvre le portail dans VOTRE Chrome habituel
   Etape 6  Il ouvre SON navigateur (une fenetre a part) et remplit une page d'essai
   Etape 7  Il ouvre le portail dans SA fenetre.
            Si le portail demande de vous connecter : connectez-vous dans SA fenetre.
            Puis il encadre en rouge ce qu'il sait cliquer (sans cliquer).
   Etape 8  Vous tapez le texte EXACT d'un menu ou d'un lien, tel qu'il est
            ecrit sur le portail (par exemple GATES) : il le trouve, l'encadre
            en rouge, et clique seulement si vous tapez o. Il ne clique jamais sur un bouton de formulaire, une
            case a cocher, ni sur Supprimer, Enregistrer, Valider, OK...
            Vous pouvez essayer jusqu'a 5 mots ; Entree sans rien = fini.

IMPORTANT : quand le robot pose une question, CLIQUEZ D'ABORD DANS LA FENETRE NOIRE,
puis repondez. (Si vous tapez « o » ailleurs, par exemple dans le Bloc-notes, il ne
le voit pas.)

Pour tout arreter a n'importe quel moment : Ctrl + C dans la fenetre noire.


3. A LA FIN : M'ENVOYER LE RESULTAT
-----------------------------------
Un cadre RESULTAT s'affiche, par exemple :

   P  Python fonctionne ........................ OK
   F  Fichiers et dossiers ..................... OK
   K  Clavier (Bloc-notes) ..................... OK
   S  Souris ................................... OK
   W  Portail dans votre navigateur ............ OK
   N  Navigateur du robot (page d'essai) ....... OK
   D  Demarrage avec un profil ................. OK
   R  Navigateur du robot sur le portail ....... OK
   C  Clic choisi sur le portail ............... OK
   CODE : P1 F1 K1 S1 W1 N1 D1 R1 C1

PRENEZ-LE EN PHOTO et envoyez-la-moi. Il est aussi ecrit dans le fichier
« resultat_prise_en_main.txt », dans le dossier « Robot - essai » du Bureau.
Il ne contient AUCUNE donnee du portail : ni adresse, ni texte des pages, ni les
mots que vous avez tapes. Seulement des OK / ECHEC et des nombres.

Si une etape dit ECHEC : ce n'est pas grave, c'est justement ce qu'on cherche a
savoir. Continuez jusqu'au bout et envoyez la photo.

Vous pouvez ensuite fermer le Bloc-notes SANS enregistrer, et supprimer le dossier
« Robot - essai » du Bureau.
