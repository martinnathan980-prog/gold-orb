================================================================================
  ETII HUB — INSTALLER LE SITE SUR GOOGLE (Google Drive + Sheets + Apps Script)
================================================================================

Ce document dit EXACTEMENT quoi faire, clic par clic, pour que le site tourne
chez Airbus, sur Google, avec :
  - une adresse du type https://script.google.com/a/macros/.../exec,
    réservée aux comptes Google de l'entreprise. CETTE ADRESSE EST LE SITE :
    on l'ouvre directement, on la met en favori, on la partage. Aucun
    Google Sites n'est nécessaire ;
  - le bouton « Modifier » pour les personnes que VOUS choisissez, et pour
    elles seules ;
  - TOUT se fait depuis le site : communications, alertes, rendez-vous,
    porteurs, organigramme, référents, documents, FAQ. Personne n'a besoin
    d'ouvrir une feuille Google pour changer le contenu ;
  - un JOURNAL propre de tout ce qui se passe sur le site, rubrique par
    rubrique (qui, quand, quoi, ce qui a changé) ;
  - une seule source extérieure : votre classeur de documents, un onglet
    par pôle (ETIIA, ETIIE, ETIII), avec les liens vers les documents.

Durée : 20 à 30 minutes, une seule fois.


--------------------------------------------------------------------------------
 CE QU'IL Y A À INSTALLER — trois choses, pas une de plus
--------------------------------------------------------------------------------

  1. etii-hub.html   Le site entier dans un seul fichier (pages, styles,
                     données, photos). Il va sur Google DRIVE. On ne le colle
                     nulle part : il est trop gros pour l'éditeur de script,
                     et le script le lit directement sur Drive.
                     -> fichier fourni : etii-hub/dist/etii-hub.html

  2. Code.gs         TOUT le code serveur (environ 530 lignes). Il se colle
                     dans l'éditeur Apps Script. Une ligne à modifier, plus
                     une pour brancher votre classeur de documents (étape 9).
                     -> fichier fourni : etii-hub/tools/apps-script/site/Code.gs
                        (recopié intégralement en ANNEXE A, à la fin)

  3. Une feuille Google « ETII Hub — base »
                     La base des modifications et le journal. Le script la
                     remplit seul ; vous n'y touchez que pour la liste des
                     éditeurs — et pour lire le journal quand vous voulez.

Il n'y a PAS d'index.html à créer dans Apps Script, PAS de fichier .js à
coller, PAS de bibliothèque à ajouter : le site est déjà complet dans
etii-hub.html, et Code.gs se contente de le servir, de garder les
modifications et de tenir le journal.


--------------------------------------------------------------------------------
 ÉTAPE 1 — Déposer le site sur Google Drive
--------------------------------------------------------------------------------

  1. Ouvrez Google Drive (drive.google.com) avec votre compte Airbus.
  2. « Nouveau »  ›  « Importer un fichier »  ›  choisissez etii-hub.html.
  3. Clic droit sur le fichier importé  ›  « Partager »  ›  « Copier le lien ».
     Le lien ressemble à :
        https://drive.google.com/file/d/1AbCdEfGh...XyZ/view?usp=sharing
     L'IDENTIFIANT est la partie entre « /d/ » et « /view » :
        1AbCdEfGh...XyZ
     Gardez-le sous la main (étape 4).
  4. Ne partagez PAS ce fichier avec d'autres personnes : le script le lit
     avec vos droits, les lecteurs n'en ont pas besoin.


--------------------------------------------------------------------------------
 ÉTAPE 2 — Créer la feuille « ETII Hub — base »
--------------------------------------------------------------------------------

  1. Ouvrez Google Sheets (sheets.new) : un classeur vide s'ouvre.
  2. Renommez-le « ETII Hub — base » (clic sur « Feuille de calcul sans
     titre », en haut à gauche).
  3. Ne créez aucun onglet vous-même : le script s'en charge (étape 5).


--------------------------------------------------------------------------------
 ÉTAPE 3 — Ouvrir l'éditeur Apps Script de CETTE feuille
--------------------------------------------------------------------------------

  1. Dans la feuille : menu « Extensions »  ›  « Apps Script ».
     Un nouvel onglet s'ouvre sur l'éditeur, avec un fichier « Code.gs ».
  2. En haut à gauche, cliquez sur « Projet sans titre » et renommez-le
     « ETII Hub ».
  3. (Conseillé) Roue dentée « Paramètres du projet » à gauche  ›
     « Fuseau horaire » : (GMT+01:00) Paris. Les heures du journal
     seront à l'heure de Paris.

  Important : le script DOIT être créé depuis la feuille (Extensions ›
  Apps Script), pas depuis script.google.com : c'est ainsi qu'il sait où
  ranger les modifications.


--------------------------------------------------------------------------------
 ÉTAPE 4 — Coller le code
--------------------------------------------------------------------------------

  1. Dans Code.gs : tout sélectionner (Ctrl+A), supprimer.
  2. Collez le contenu COMPLET du fichier Code.gs fourni (ANNEXE A).
  3. Cherchez la ligne :
        var ID_FICHIER_SITE = 'COLLEZ_ICI_L_IDENTIFIANT_DU_FICHIER';
     et remplacez COLLEZ_ICI_L_IDENTIFIANT_DU_FICHIER par l'identifiant de
     l'étape 1, en gardant les apostrophes :
        var ID_FICHIER_SITE = '1AbCdEfGh...XyZ';
  4. Enregistrez : icône disquette, ou Ctrl+S.

  C'est la seule ligne OBLIGATOIRE. La ligne des documents se remplit à
  l'étape 9.


--------------------------------------------------------------------------------
 ÉTAPE 5 — Lancer l'installation (une seule fois)
--------------------------------------------------------------------------------

  1. Dans la barre d'outils de l'éditeur, la liste déroulante des fonctions :
     choisissez « installer ».
  2. Cliquez « Exécuter ».
  3. Google demande l'autorisation (lire le fichier sur Drive, écrire dans
     la feuille, connaître l'adresse de la personne connectée) :
        « Examiner les autorisations »  ›  votre compte Airbus  ›  « Autoriser ».
     Si un écran « Google n'a pas validé cette application » apparaît :
        « Paramètres avancés »  ›  « Accéder à ETII Hub (non sécurisé) »
     — c'est votre propre script, il ne sort pas de votre compte.
  4. En bas, le « Journal d'exécution » affiche :
        Onglets prêts. Premier éditeur : votre.adresse@airbus.com
        Fichier du site trouvé : etii-hub.html (6… Ko).
  5. Revenez sur la feuille. Les onglets sont prêts, dans cet ordre :
        Éditeurs                          la liste des personnes qui modifient
        Journal complet                   tout ce qui se passe, le plus récent en haut
        Journal · Communication center    les communications, le mot du chef, les alertes
        Journal · À venir                 les rendez-vous de la frise
        Journal · Porteurs                les fiches des appareils
        Journal · Organigramme            personnes, squads, référents
        Journal · Documents               les documents ajoutés ou modifiés dans le site
        Journal · Questions fréquentes    la FAQ des pôles
        Journal · Réunions                les comptes rendus
        modifications                     la mémoire du site (n'y touchez pas)
     L'onglet vide « Feuille 1 » a été retiré. Votre adresse est déjà dans
     « Éditeurs ».


--------------------------------------------------------------------------------
 ÉTAPE 6 — Publier le site (déploiement en application web)
--------------------------------------------------------------------------------

  1. En haut à droite de l'éditeur : bouton bleu « Déployer »  ›
     « Nouveau déploiement ».
  2. Roue dentée à côté de « Sélectionner le type »  ›  « Application Web ».
  3. Remplissez :
        Description        : ETII Hub
        Exécuter en tant que : Moi (votre.adresse@airbus.com)
        Qui a accès        : Tous les utilisateurs de votre organisation
                             (libellé exact selon la console : « Toute
                             personne de Airbus » / « Anyone within … »)
  4. « Déployer ». Si Google redemande l'autorisation : « Autoriser ».
  5. Copiez l'« URL de l'application Web » (elle finit par /exec).
     C'est L'ADRESSE DU SITE. Mettez-la en favori, envoyez-la à l'équipe :
     c'est tout. (Pas de Google Sites : le site s'ouvre en plein écran,
     directement.)

  Pourquoi « Exécuter en tant que : Moi » : la feuille reste privée (seul
  le script y écrit, avec vos droits), et le site connaît l'adresse de la
  personne connectée parce qu'elle est du même domaine que vous.


--------------------------------------------------------------------------------
 ÉTAPE 7 — Vérifier
--------------------------------------------------------------------------------

  1. Ouvrez l'adresse /exec. Le premier affichage prend quelques secondes
     (le fichier pèse environ 6,5 Mo) ; ensuite, la navigation entre les
     pages est immédiate.
  2. Vous voyez le bouton « ✎ Modifier » dans la barre du haut.
  3. Cliquez-le : un bandeau dit « Mode édition. Ce que vous ajoutez,
     modifiez ou supprimez est enregistré pour tous les lecteurs du site.
     Connecté : votre.adresse@airbus.com. », avec un bouton « Historique ».
  4. Ajoutez un rendez-vous d'essai dans « À venir », rechargez la page :
     il est toujours là. Dans la feuille, l'onglet « Journal · À venir »
     a une ligne : la date, votre adresse, « Ajout », le titre du
     rendez-vous et ses champs. Supprimez-le ensuite depuis le site : une
     ligne « Suppression » s'ajoute au-dessus.
  5. Demandez à un collègue (qui n'est PAS dans « Éditeurs ») d'ouvrir
     l'adresse : il voit tout, mais n'a pas de bouton « Modifier ».


--------------------------------------------------------------------------------
 ÉTAPE 8 — Donner (ou retirer) le droit de modifier
--------------------------------------------------------------------------------

  Onglet « Éditeurs » de la feuille :
     colonne A : une adresse Airbus par ligne (ex. prenom.nom@airbus.com)
     colonne B : un nom, facultatif
  C'est tout. L'effet est immédiat : la personne a le bouton « Modifier »
  au prochain chargement du site. Pour retirer le droit : supprimez sa
  ligne.

  Le serveur vérifie l'adresse à CHAQUE enregistrement : quelqu'un qui
  n'est pas dans la liste ne peut rien écrire, même en bricolant sa page.


--------------------------------------------------------------------------------
 ÉTAPE 9 — Brancher vos documents : un classeur, un onglet par pôle
--------------------------------------------------------------------------------

  C'est la SEULE chose que le site va chercher à l'extérieur : la liste de
  vos documents, avec leurs liens. Sans cette étape, la « Recherche » et
  les « Documents du pôle » montrent des EXEMPLES fictifs.

  Le classeur attendu : UN classeur Google Sheets, avec TROIS onglets
  nommés ETIIA, ETIIE et ETIII. Chaque onglet liste les documents de son
  pôle, une ligne par document. Le nom de l'onglet suffit à dire le pôle.

  Des milliers de fichiers déjà rangés dans un Drive partagé ? Ne les
  recopiez pas : le script tools/apps-script/index-documents.gs remplit
  ces onglets tout seul, chaque nuit (docs/ASSISTANT-IA.md, étape 1.3).

  1. Ouvrez votre classeur de documents. Son adresse ressemble à :
        https://docs.google.com/spreadsheets/d/1XyZ…AbC/edit#gid=0
     L'identifiant est entre « /d/ » et « /edit ».
  2. Vérifiez les noms des onglets : ETIIA, ETIIE, ETIII. S'ils
     s'appellent autrement (« Documents ETIIA »…), soit vous les renommez,
     soit vous changez la ligne DOCUMENTS_ONGLETS dans Code.gs — le code du
     pôle doit rester dans le nom.
  3. Vérifiez la ligne 1 de chaque onglet (les titres de colonnes). Le site
     reconnaît, sans tenir compte des accents ni des majuscules :
        Titre (ou Intitulé, Nom du document)   — OBLIGATOIRE
        Lien (ou URL)                          — l'adresse du document
        Référence (ou Réf, Numéro, Code)
        Type (ou Type de document, Nature, Catégorie)
        Métier (ou Domaine)                    — plusieurs : séparés par « , » ou « ; »
        Porteur (ou Responsable, Auteur, Propriétaire)
        Périmètre (ou Programme, Appareil)     — H160, Transverse…
        Mise à jour (ou Date)                  — une date, ou « 15/07/2026 »
        Description (ou Résumé, Objet)
        Mots-clés (ou Tags)
        Remplacé par                           — la référence de la nouvelle version
        Pôle                                   — facultatif : l'onglet le dit déjà
     Les autres colonnes sont ignorées. Renommez un titre si besoin : c'est
     tout ce qu'il y a à adapter. Les trois onglets n'ont pas besoin
     d'avoir les mêmes colonnes, ni dans le même ordre.
  4. Dans Code.gs, remplissez :
        var DOCUMENTS_ID_FEUILLE = '1XyZ…AbC';
     (la ligne DOCUMENTS_ONGLETS, juste en dessous, vaut déjà
      ['ETIIA', 'ETIIE', 'ETIII'])
  5. Enregistrez. Pour vérifier tout de suite : relancez « installer » —
     le journal d'exécution dit « Documents lus : 143 » (ou signale
     l'onglet qui manque).
  6. « Déployer » › « Gérer les déploiements » › crayon › « Version :
     Nouvelle version » › « Déployer ».
  7. Rechargez le site : la Recherche montre vos documents ; chaque page
     de pôle, ceux de son onglet.

  Bon à savoir :
  - Le script lit ce classeur avec VOS droits : les lecteurs n'ont pas
    besoin d'y avoir accès.
  - Il le lit à chaque ouverture du site : un document ajouté dans le
    classeur apparaît au prochain chargement.
  - Le site ne modifie JAMAIS votre classeur. Un document ajouté ou
    modifié depuis le site (bouton « Modifier ») est gardé par le site
    (onglet « modifications »), s'affiche par-dessus le classeur, et se
    lit dans « Journal · Documents ». Pour que le classeur reprenne la
    main sur un document modifié dans le site, supprimez sa ligne dans
    l'onglet « modifications ».
  - Un onglet manquant n'empêche pas les deux autres de s'afficher. Si
    tout le classeur devient illisible (supprimé, droits retirés), le site
    s'affiche quand même, avec les documents d'exemple.


--------------------------------------------------------------------------------
 LE JOURNAL — suivre tout ce qui se passe sur le site
--------------------------------------------------------------------------------

  Chaque ajout, modification ou suppression faite dans le site écrit une
  ligne, LA PLUS RÉCENTE EN HAUT, à deux endroits :
     « Journal complet »            tout, toutes rubriques confondues ;
     « Journal · <la rubrique> »    le même geste, dans l'onglet de sa
                                    rubrique.

  Les colonnes :
     Date             jour et heure (heure de Paris, si réglée à l'étape 3)
     Qui              l'adresse de la personne
     Rubrique         Communication center, À venir, Porteurs,
                      Organigramme, Documents, Questions fréquentes,
                      Réunions (dans « Journal complet » seulement)
     Pôle             ETIIA, ETIIE, ETIII — quand l'élément en a un
     Action           Ajout (vert), Modification (jaune), Suppression
                      (rouge), Annulation (violet)
     Élément          le titre, le nom ou le code de ce qui a changé
     Ce qui a changé  une ligne par champ, avant → après :
                         Date : « 2026-10-02 » → « 2026-10-09 »
                         Lieu : (vide) → « Salle Gouverneur »
                      pour un ajout, les premiers champs remplis.

  Dans la feuille, un filtre (« Données » › « Créer un filtre ») sur la
  colonne Pôle ou Qui isole un pôle ou une personne.

  Dans le site aussi : en mode édition, le bouton « Historique » du
  bandeau ouvre les 300 derniers gestes, jour par jour, avec un filtre par
  rubrique. Il n'est visible que des éditeurs.


--------------------------------------------------------------------------------
 OÙ VIVENT LES DONNÉES — en une page
--------------------------------------------------------------------------------

  Ce qui s'affiche au départ (la BASE)
     Dans etii-hub.html : communications, rendez-vous, porteurs,
     organigramme, FAQ, comptes rendus. Ce sont les fichiers de données du
     projet (assets/data/*.json), intégrés au fichier.

  Ce qu'on change dans le site (les MODIFICATIONS)
     Bouton « Modifier » › Ajouter / Modifier / Supprimer : une
     communication, une alerte, un rendez-vous, un porteur, une personne,
     une squad, un référent, un document, une question, un compte rendu…
     Tout part dans l'onglet « modifications » de « ETII Hub — base », et
     s'affiche par-dessus la base, pour tout le monde, au chargement
     suivant. Chaque geste est raconté dans les onglets Journal.

  Ce qui vient de l'extérieur (la SEULE source)
     La liste des documents et leurs liens : votre classeur, un onglet par
     pôle (étape 9). Plus tard, si vous le souhaitez : le suivi OTQ / OTD
     (voir docs/OTQ-GOOGLE-SHEETS.md).


--------------------------------------------------------------------------------
 METTRE À JOUR LE SITE PLUS TARD
--------------------------------------------------------------------------------

  Nouvelle version d'etii-hub.html (nouvelles pages, nouveau design) :
     Drive  ›  clic droit sur etii-hub.html  ›  « Informations sur le
     fichier »  ›  « Gérer les versions »  ›  « Importer une nouvelle
     version ».
     L'identifiant ne change pas : rien à faire dans le script, rien à
     redéployer. Rechargez simplement le site.
     Les modifications faites dans le site sont CONSERVÉES : elles sont
     dans la feuille, pas dans le fichier.

  Nouvelle version de Code.gs (rare) :
     collez le nouveau code (gardez vos lignes ID_FICHIER_SITE et
     DOCUMENTS_ID_FEUILLE), enregistrez, relancez « installer » (il
     n'abîme rien : il complète les onglets qui manquent), puis
     « Déployer »  ›  « Gérer les déploiements »  ›  crayon  ›
     « Version : Nouvelle version »  ›  « Déployer ». L'adresse /exec ne
     change pas.


--------------------------------------------------------------------------------
 LA FEUILLE, EN DEUX MOTS
--------------------------------------------------------------------------------

  - « Éditeurs » : la seule chose que vous gérez.
  - « Journal complet » et « Journal · … » : l'historique lisible. Rien à
    y faire, sauf le lire (et filtrer).
  - « modifications » : la mémoire du site, une ligne par élément ajouté,
    modifié ou supprimé. Ne la modifiez pas à la main. Seule exception :
    supprimer une ligne annule la modification (l'élément redevient celui
    d'origine).
  - Sauvegarde : « Fichier »  ›  « Historique des versions » de la feuille
    permet de revenir à n'importe quel état passé.


--------------------------------------------------------------------------------
 SI QUELQUE CHOSE NE VA PAS
--------------------------------------------------------------------------------

  « Exception: … No item with the given ID could be found » (ou page
  d'erreur à l'ouverture)
     -> l'identifiant de l'étape 4 est faux, ou le fichier a été supprimé
        ou déplacé dans une corbeille. Recopiez l'identifiant.

  Le bouton « Modifier » n'apparaît pas pour un éditeur
     -> son adresse n'est pas exactement dans la colonne A d'« Éditeurs »
        (espace en trop, autre alias) ; ou le déploiement n'est pas en
        « Exécuter en tant que : Moi ».

  Les documents d'exemple restent affichés
     -> DOCUMENTS_ID_FEUILLE est vide, ou le déploiement n'a pas été
        mis à jour (« Nouvelle version », étape 9.6). Relancez
        « installer » : le journal d'exécution dit ce qu'il a lu.

  Un pôle n'a pas ses documents
     -> son onglet ne s'appelle pas ETIIA / ETIIE / ETIII, ou sa ligne 1
        n'a pas de colonne « Titre ».

  « Cette application a été bloquée par votre administrateur » /
  « Apps Script est désactivé »
     -> la DSI encadre Apps Script ou les applications web. Demandez
        l'autorisation pour une application web interne : exécutée par
        vous, accès limité au domaine Airbus, données internes au service,
        aucun appel vers l'extérieur.

  Un collègue ne voit pas une modification
     -> il doit recharger la page (le site lit les modifications à
        l'ouverture).

  Le premier chargement est lent
     -> normal : tout le site (photos comprises) arrive d'un coup, puis
        plus rien ne se recharge d'une page à l'autre.


--------------------------------------------------------------------------------
 LES PROFILS : QUI VOIT, QUI MODIFIE
--------------------------------------------------------------------------------

  Oui, c'est possible dans l'environnement Airbus, et c'est ce que ce
  montage fait : le site sait QUI est connecté.

  - Tout le monde s'identifie déjà : pour ouvrir l'adresse /exec, il faut
    être connecté à son compte Google Airbus (c'est le cas de toute
    personne qui ouvre Gmail ou Drive). Aucun mot de passe de plus.
  - Le serveur (Code.gs) lit l'adresse de la personne connectée
    (Session.getActiveUser), la compare à l'onglet « Éditeurs », et
    répond au site : « peut modifier » ou « lecture seule ».
  - Le bouton « Modifier » n'apparaît que pour les éditeurs. Surtout, le
    serveur refuse toute écriture d'une adresse absente de la liste :
    ce n'est pas qu'un bouton caché.
  - Chaque modification est signée : les onglets Journal disent qui a
    changé quoi, et quand. L'Historique du site aussi (éditeurs seuls).
  - On peut aller plus loin plus tard (un rôle par pôle : les éditeurs
    d'ETIIA ne modifient que la page ETIIA…) : il suffira d'une colonne
    « pôle » dans « Éditeurs ». Dites-le si c'est utile.

  Condition : le déploiement « Exécuter en tant que : Moi » + « Tous les
  utilisateurs de votre organisation ». Une personne hors du domaine Airbus
  (ou avec un compte Gmail personnel) n'ouvre pas le site.

            et DOCUMENTS_ID_FEUILLE, étape 9)

var ENTETE_RUBRIQUE = ['Date', 'Qui', 'Pôle', 'Action', 'Élément', 'Ce qui a changé'];
var JEUX = ['communications', 'flotte', 'organigramme', 'faq', 'documents', 'reunions'];
/* La rubrique d'une modification, décidée ici d'après le jeu et le type :

  communications: { annonce: 'Communication center', edito: 'Communication center', alerte: 'Communication center', agenda: 'À venir' },
  flotte: { porteur: 'Porteurs' },
  organigramme: { personne: 'Organigramme', squad: 'Organigramme' },
  documents: { document: 'Documents' },
  faq: { question: 'Questions fréquentes' },
  reunions: { 'compte-rendu': 'Réunions' }
};
var ORDRE_RUBRIQUES = ['Communication center', 'À venir', 'Porteurs', 'Organigramme', 'Documents', 'Questions fréquentes', 'Réunions'];
var ACTIONS = ['Ajout', 'Modification', 'Suppression', 'Annulation'];
var COULEURS_ACTION = { 'Ajout': '#e2efe3', 'Modification': '#f7ecd4', 'Suppression': '#f6dfdb', 'Annulation': '#e6e2ef' };
var POLES = ['ETIIA', 'ETIIE', 'ETIII'];
/* Une cellule de feuille Google tient 50 000 caractères : un élément plus

   un nombre ou une date. */
var TRANCHE = 40000;
var MARQUE = '~';
var EN_TETE = ['jeu', 'cle', 'type', 'id', 'op', 'le', 'par', 'donnees'];

function doGet() {
  var html = DriveApp.getFileById(ID_FICHIER_SITE).getBlob().getDataAsString('UTF-8');
  return HtmlService.createHtmlOutput(html)
    .setTitle('ETII Hub')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1')

    // une autre page (Google Sites), remplacer DEFAULT par ALLOWALL.
    .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.DEFAULT);
}

/**
 * Au chargement de chaque page : qui est connecté, peut-il modifier, et
 * toutes les modifications, jeu par jeu.
 */
function etiiDemarrer() {
  var email = emailConnecte_();
  var reponse = {
    email: email,
    peutModifier: peutModifier_(email),
    modifications: lireModifications_(),
    bases: {}
  };
  /* Les documents, lus dans leur classeur, s'il est branché. Un classeur
     illisible ne bloque pas le site : il garde ses documents. Un onglet
     manquant n'empêche pas de lire les autres ; le site le signale. */
  if (DOCUMENTS_ID_FEUILLE) {
    try {
      var lecture = lireDocumentsExternes_();
      reponse.bases.documents = lecture.documents;
      if (lecture.avertissements.length) reponse.basesErreur = 'Documents : ' + lecture.avertissements.join(' ; ');
    } catch (e) {
      reponse.basesErreur = 'Liste des documents illisible : ' + e.message;
    }
  }
  return reponse;
}

/**
 * Enregistre un élément ajouté, modifié ou supprimé.
 * @param {string} jeu    communications, flotte, organigramme, faq, documents, reunions
 * @param {Object} modif  { type, id, op: 'maj'|'suppr', donnees, journal }
 *   journal : ce que le site a vu changer, en clair —
 *   { action: 'Ajout'|'Modification'|'Suppression', element, pole, detail }
 * @return {{le: string, par: string}}
 */
function etiiPoser(jeu, modif) {
  var email = emailConnecte_();
  if (!peutModifier_(email)) throw new Error('NON_AUTORISE');
  verifierJeu_(jeu);
  if (!modif || typeof modif !== 'object') throw new Error('Modification illisible.');
  var type = String(modif.type || '').trim();
  var id = String(modif.id || '').trim();
  var op = modif.op === 'suppr' ? 'suppr' : (modif.op === 'maj' ? 'maj' : '');
  if (!type || !id || !op) throw new Error('Modification illisible.');
  var donnees = op === 'maj' ? JSON.stringify(modif.donnees || {}) : '';
  var le = new Date().toISOString();

  var verrou = LockService.getScriptLock();
  verrou.waitLock(20000);
  try {
    var feuille = onglet_(ONGLET_MODIFICATIONS, EN_TETE);
    var cle = type + '~' + id;
    var ligne = trouverLigne_(feuille, jeu, cle);
    var valeurs = [jeu, cle, type, id, op, le, email].concat(decouper_(donnees));
    if (ligne) {
      // L'ancienne version peut avoir occupé plus de colonnes : on les vide.
      var largeur = Math.max(feuille.getLastColumn(), valeurs.length);
      feuille.getRange(ligne, 1, 1, largeur).clearContent();
      feuille.getRange(ligne, 1, 1, valeurs.length).setValues([valeurs]);
    } else {
      feuille.appendRow(valeurs);
    }
    journaliser_(email, jeu, type, id, op, modif.journal, modif.donnees);
  } finally {
    verrou.releaseLock();
  }
  return { le: le, par: email };
}

/**
 * Annule une modification : l'élément redevient celui du fichier d'origine.
 */
function etiiRetirer(jeu, type, id) {
  var email = emailConnecte_();
  if (!peutModifier_(email)) throw new Error('NON_AUTORISE');
  verifierJeu_(jeu);
  var cle = String(type || '').trim() + '~' + String(id || '').trim();
  var verrou = LockService.getScriptLock();
  verrou.waitLock(20000);
  try {
    var feuille = onglet_(ONGLET_MODIFICATIONS, EN_TETE);
    var ligne = trouverLigne_(feuille, jeu, cle);
    if (ligne) feuille.deleteRow(ligne);
    journaliser_(email, jeu, String(type || ''), String(id || ''), 'annulation',
      { detail: 'L’élément redevient celui du fichier d’origine.' }, null);
  } finally {
    verrou.releaseLock();
  }
  return { ok: true };
}

/**
 * Les dernières lignes du journal, la plus récente d'abord : l'Historique
 * du site. Réservé aux éditeurs (il porte des adresses).
 * @param {number} limite  combien de lignes (200 par défaut, 1000 au plus)
 */
function etiiJournal(limite) {
  var email = emailConnecte_();
  if (!peutModifier_(email)) throw new Error('NON_AUTORISE');
  var n = Math.min(Math.max(Number(limite) || 200, 1), 1000);
  var feuille = classeur_().getSheetByName(ONGLET_JOURNAL);
  if (!feuille || feuille.getLastRow() < 2) return [];
  var lignes = feuille.getRange(2, 1, Math.min(n, feuille.getLastRow() - 1), ENTETE_JOURNAL.length).getValues();
  return lignes.map(function (l) {
    var quand = l[0];
    return {
      le: estDate_(quand) ? quand.toISOString() : String(quand || ''),
      par: String(l[1] || ''),
      rubrique: String(l[2] || ''),
      pole: String(l[3] || ''),
      action: String(l[4] || ''),
      element: String(l[5] || ''),
      detail: String(l[6] || '')
    };
  });
}

/**
 * Crée les onglets, s'inscrit comme premier éditeur et vérifie que le
 * fichier du site est lisible. Le journal d'exécution dit ce qui a été fait.
 */
function installer() {
  PropertiesService.getScriptProperties().setProperty('ID_CLASSEUR', SpreadsheetApp.getActiveSpreadsheet().getId());
  var editeurs = onglet_(ONGLET_EDITEURS, ['adresse', 'nom (facultatif)']);
  ongletJournal_(ONGLET_JOURNAL, ENTETE_JOURNAL);
  ORDRE_RUBRIQUES.forEach(function (r) { ongletJournal_(PREFIXE_JOURNAL + r, ENTETE_RUBRIQUE); });
  onglet_(ONGLET_MODIFICATIONS, EN_TETE);
  /* L'onglet vide que Google crée avec le classeur (« Feuille 1 ») ne
     sert à rien : on le retire, la feuille ne montre que les nôtres. */
  var classeur = classeur_();
  classeur.getSheets().forEach(function (f) {
    if (/^(Feuille|Sheet)\s*\d+$/i.test(f.getName()) && f.getLastRow() === 0 && classeur.getSheets().length > 1) classeur.deleteSheet(f);
  });
  var moi = Session.getEffectiveUser().getEmail();
  if (moi && listeEditeurs_().indexOf(moi.toLowerCase()) === -1) editeurs.appendRow([moi, 'propriétaire']);
  var fichier = DriveApp.getFileById(ID_FICHIER_SITE);
  Logger.log('Onglets prêts. Premier éditeur : ' + moi);
  Logger.log('Fichier du site trouvé : ' + fichier.getName() + ' (' + Math.round(fichier.getSize() / 1024) + ' Ko).');
  if (DOCUMENTS_ID_FEUILLE) {
    try {
      var lecture = lireDocumentsExternes_();
      Logger.log('Documents lus : ' + lecture.documents.length
        + (lecture.avertissements.length ? ' (' + lecture.avertissements.join(' ; ') + ')' : '') + '.');
    } catch (e) {
      Logger.log('Documents illisibles : ' + e.message);
    }
  }
}

/* Les titres de colonne reconnus pour chaque champ d'un document, écrits
   sans accents, sans espaces ni ponctuation, en minuscules. */
var COLONNES_DOCUMENTS = {
  id: ['id', 'identifiantunique'],
  titre: ['titre', 'title', 'intitule', 'nomdudocument', 'document', 'nom', 'libelle'],
  reference: ['reference', 'ref', 'numero', 'no', 'code', 'identifiant'],
  type: ['type', 'typedocument', 'typededocument', 'nature', 'categorie'],
  metier: ['metier', 'metiers', 'domaine', 'discipline'],
  porteur: ['porteur', 'responsable', 'auteur', 'proprietaire', 'redacteur'],
  perimetre: ['perimetre', 'programme', 'appareil', 'produit', 'helicoptere'],
  pole: ['pole', 'poles', 'equipe'],
  maj: ['maj', 'miseajour', 'datemaj', 'datedemiseajour', 'derniereversion', 'modifiele', 'date'],
  lien: ['lien', 'url', 'link', 'adresse', 'chemin'],
  description: ['description', 'resume', 'objet', 'commentaire'],
  motsCles: ['motscles', 'motcle', 'tags', 'keywords'],
  remplacePar: ['remplacepar', 'supersededby']
};
var CHAMPS_LISTES = ['metier', 'pole', 'motsCles'];

function cleColonne_(t) {
  return String(t || '').toLowerCase().normalize('NFD').replace(/[\u0300-\u036f]/g, '').replace(/[^a-z0-9]/g, '');
}

/**
 * Lit le classeur des documents : un onglet par pôle (DOCUMENTS_ONGLETS),
 * une ligne par document, les colonnes reconnues par leur titre (ligne 1).
 * Les autres colonnes sont ignorées. Un onglet absent ou sans colonne
 * « Titre » est signalé et sauté ; si aucun ne se lit, c'est une erreur.
 * @return {{documents: Object[], avertissements: string[]}}
 */
function lireDocumentsExternes_() {
  var classeur = SpreadsheetApp.openById(DOCUMENTS_ID_FEUILLE);
  var documents = [];
  var avertissements = [];
  var vus = {};
  var lus = 0;
  DOCUMENTS_ONGLETS.forEach(function (nom) {
    var feuille = classeur.getSheetByName(nom);
    if (!feuille) { avertissements.push('onglet « ' + nom + ' » introuvable'); return; }
    try {
      lireOngletDocuments_(feuille, nom, documents, vus);
      lus += 1;
    } catch (e) {
      avertissements.push('onglet « ' + nom + ' » : ' + e.message);
    }
  });
  if (!lus) throw new Error(avertissements.join(' ; ') || 'aucun onglet de documents');
  return { documents: documents, avertissements: avertissements };
}

function lireOngletDocuments_(feuille, nom, documents, vus) {
  if (feuille.getLastRow() < 1 || feuille.getLastColumn() < 1) return;
  var valeurs = feuille.getRange(1, 1, feuille.getLastRow(), feuille.getLastColumn()).getValues();
  var entetes = valeurs[0].map(cleColonne_);
  var position = {};
  Object.keys(COLONNES_DOCUMENTS).forEach(function (champ) {
    var noms = COLONNES_DOCUMENTS[champ];
    for (var i = 0; i < noms.length; i++) {
      var j = entetes.indexOf(noms[i]);
      if (j !== -1) { position[champ] = j; return; }
    }
  });
  if (position.titre === undefined) throw new Error('aucune colonne « Titre »');
  /* Le pôle de l'onglet : son nom contient le code (« ETIIA »,
     « Documents ETIIE »). Une colonne Pôle remplie a le dernier mot. */
  var trouve = /ETII[AEI]/i.exec(String(nom));
  var poleOnglet = trouve ? trouve[0].toUpperCase() : '';
  var fuseau = Session.getScriptTimeZone ? Session.getScriptTimeZone() : 'Europe/Paris';
  for (var r = 1; r < valeurs.length; r++) {
    var ligne = valeurs[r];
    var doc = {};
    Object.keys(position).forEach(function (champ) {
      var v = ligne[position[champ]];
      if (estDate_(v)) v = Utilities.formatDate(v, fuseau, 'yyyy-MM-dd');
      v = String(v === null || v === undefined ? '' : v).trim();
      if (champ === 'maj') {
        var fr = /^(\d{1,2})\/(\d{1,2})\/(\d{4})$/.exec(v);
        if (fr) v = fr[3] + '-' + ('0' + fr[2]).slice(-2) + '-' + ('0' + fr[1]).slice(-2);
      }
      if (CHAMPS_LISTES.indexOf(champ) !== -1) {
        doc[champ] = v ? v.split(/\s*[,;\n]\s*/).filter(function (x) { return x; }) : [];
      } else if (v) {
        doc[champ] = v;
      }
    });
    if (!doc.titre) continue;
    if ((!doc.pole || !doc.pole.length) && poleOnglet) doc.pole = [poleOnglet];
    /* L'identifiant : la colonne « id », sinon la référence, sinon
       l'onglet et la ligne. C'est lui qui relie une modification faite
       dans le site. */
    var id = doc.id || doc.reference || (nom + '-ligne-' + (r + 1));
    while (vus[id]) id = id + '-' + (r + 1);
    vus[id] = true;
    doc.id = id;
    documents.push(doc);
  }
}

function emailConnecte_() {
  var email = '';
  try { email = Session.getActiveUser().getEmail() || ''; } catch (e) { email = ''; }
  return String(email).trim().toLowerCase();
}

function peutModifier_(email) {
  if (!email) return false;
  var proprietaire = String(Session.getEffectiveUser().getEmail() || '').toLowerCase();
  if (email === proprietaire) return true;
  return listeEditeurs_().indexOf(email) !== -1;
}

function listeEditeurs_() {
  var feuille = classeur_().getSheetByName(ONGLET_EDITEURS);
  if (!feuille || feuille.getLastRow() < 2) return [];
  return feuille.getRange(2, 1, feuille.getLastRow() - 1, 1).getValues()
    .map(function (l) { return String(l[0] || '').trim().toLowerCase(); })
    .filter(function (a) { return a.indexOf('@') > 0; });
}

function lireModifications_() {
  var resultat = {};
  JEUX.forEach(function (j) { resultat[j] = []; });
  var feuille = classeur_().getSheetByName(ONGLET_MODIFICATIONS);
  if (!feuille || feuille.getLastRow() < 2) return resultat;
  var lignes = feuille.getRange(2, 1, feuille.getLastRow() - 1, feuille.getLastColumn()).getValues();
  lignes.forEach(function (l) {
    var jeu = String(l[0] || '');
    if (!resultat[jeu]) return;
    var op = String(l[4] || '');
    var donnees = null;
    if (op === 'maj') {
      var json = l.slice(7).map(function (c) {
        var t = String(c === null || c === undefined ? '' : c);
        return t.charAt(0) === MARQUE ? t.substring(1) : t;
      }).join('');
      try { donnees = JSON.parse(json); } catch (e) { return; }
    }
    resultat[jeu].push({ type: String(l[2]), id: String(l[3]), op: op, donnees: donnees, le: String(l[5] || ''), par: String(l[6] || '') });
  });
  return resultat;
}

function trouverLigne_(feuille, jeu, cle) {
  var n = feuille.getLastRow();
  if (n < 2) return 0;
  var valeurs = feuille.getRange(2, 1, n - 1, 2).getValues();
  for (var i = 0; i < valeurs.length; i++) {
    if (String(valeurs[i][0]) === jeu && String(valeurs[i][1]) === cle) return i + 2;
  }
  return 0;
}

function decouper_(texte) {
  if (!texte) return [''];
  var morceaux = [];
  for (var i = 0; i < texte.length; i += TRANCHE) morceaux.push(MARQUE + texte.substring(i, i + TRANCHE));
  return morceaux;
}

function titreDe_(donnees) {
  if (!donnees || typeof donnees !== 'object') return '';
  return String(donnees.titre || donnees.nom || donnees.question || donnees.code || donnees.texte || '').slice(0, 120);
}

function poleDe_(donnees) {
  if (!donnees || typeof donnees !== 'object') return '';
  var v = donnees.poles !== undefined ? donnees.poles : donnees.pole;
  return (Array.isArray(v) ? v : [v]).map(function (x) { return String(x === null || x === undefined ? '' : x).trim(); })
    .filter(function (x) { return x; }).join(', ');
}

function court_(v, n) {
  var t = String(v === null || v === undefined ? '' : v).trim();
  return t.length > n ? t.substring(0, n - 1) + '…' : t;
}

function estDate_(v) {
  return Object.prototype.toString.call(v) === '[object Date]';
}

/* Une cellule qui commence par « = », « + », « - » ou « @ » serait lue
   comme une formule : l'apostrophe la garde en texte (elle ne s'affiche
   pas). */
function enTexte_(v) {
  return (typeof v === 'string' && /^[=+\-@]/.test(v)) ? "'" + v : v;
}

/**
 * Une ligne de journal, la plus récente en haut, dans « Journal complet »
 * et dans l'onglet de sa rubrique. La rubrique est décidée ici ; le site
 * ne fournit que le récit (action, élément, pôle, ce qui a changé).
 */
function journaliser_(email, jeu, type, id, op, infos, donnees) {
  var j = (infos && typeof infos === 'object') ? infos : {};
  var rubrique = (RUBRIQUES[jeu] && RUBRIQUES[jeu][type]) || 'Autres';
  var action = op === 'annulation' ? 'Annulation'
    : (op === 'suppr' ? 'Suppression' : (j.action === 'Ajout' ? 'Ajout' : 'Modification'));
  var element = court_(j.element, 200) || titreDe_(donnees) || id;
  var pole = court_(j.pole, 60) || poleDe_(donnees);
  var detail = court_(j.detail, 3000);
  var quand = new Date();
  ecrireJournal_(ONGLET_JOURNAL, ENTETE_JOURNAL, [quand, email, rubrique, pole, action, element, detail]);
  ecrireJournal_(PREFIXE_JOURNAL + rubrique, ENTETE_RUBRIQUE, [quand, email, pole, action, element, detail]);
}

function ecrireJournal_(nom, entete, ligne) {
  var feuille = ongletJournal_(nom, entete);
  feuille.insertRowAfter(1);
  var plage = feuille.getRange(2, 1, 1, ligne.length);
  plage.setValues([ligne.map(enTexte_)]);
  plage.setFontWeight('normal').setBackground(null).setFontColor('#2a251f');
  feuille.getRange(2, 1).setNumberFormat('dd/MM/yyyy HH:mm');
  var colonneAction = entete.indexOf('Action') + 1;
  feuille.getRange(2, colonneAction).setBackground(COULEURS_ACTION[ligne[colonneAction - 1]] || null);
}

/* Un onglet de journal, mis en forme à sa création : en-tête figé et
   teinté, colonnes à leur largeur, le détail qui passe à la ligne. */
function ongletJournal_(nom, entete) {
  var classeur = classeur_();
  var feuille = classeur.getSheetByName(nom);
  if (feuille) return feuille;
  feuille = classeur.insertSheet(nom);
  feuille.getRange(1, 1, 1, entete.length).setValues([entete])
    .setFontWeight('bold').setBackground('#e9e1d3').setFontColor('#2a251f');
  feuille.setFrozenRows(1);
  var largeurs = { 'Date': 130, 'Qui': 210, 'Rubrique': 170, 'Pôle': 90, 'Action': 110, 'Élément': 300, 'Ce qui a changé': 560 };
  entete.forEach(function (t, i) { if (largeurs[t]) feuille.setColumnWidth(i + 1, largeurs[t]); });
  feuille.getRange(1, entete.length, feuille.getMaxRows(), 1).setWrap(true);
  return feuille;
}

function verifierJeu_(jeu) {
  if (JEUX.indexOf(jeu) === -1) throw new Error('Jeu de données inconnu : ' + jeu);
}

/* La feuille où vit ce script. Son identifiant est retenu par
   installer() : l'application web la retrouve ainsi à coup sûr. */
function classeur_() {
  var id = PropertiesService.getScriptProperties().getProperty('ID_CLASSEUR');
  return id ? SpreadsheetApp.openById(id) : SpreadsheetApp.getActiveSpreadsheet();
}

function onglet_(nom, entete) {
  var classeur = classeur_();
  var feuille = classeur.getSheetByName(nom);
  if (!feuille) {
    feuille = classeur.insertSheet(nom);
    feuille.getRange(1, 1, 1, entete.length).setValues([entete]).setFontWeight('bold');
    feuille.setFrozenRows(1);
    // Tout en texte brut : un identifiant « 007 » reste « 007 », une date
    // reste la chaîne écrite par le site.
    if (nom === ONGLET_MODIFICATIONS) feuille.getRange(1, 1, feuille.getMaxRows(), feuille.getMaxColumns()).setNumberFormat('@');
  }
  return feuille;
}
