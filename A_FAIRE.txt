ROBOT - CE QUE TU FAIS
======================

A. RECEVOIR LE ROBOT (une seule fois, ou quand je t'en envoie un nouveau)
1. Dans Téléchargements, supprime l'ancien robot.txt s'il y en a un.
2. Enregistre robot.txt dans Téléchargements.

B. LANCER LE ROBOT (à chaque fois)
3. Ouvre le dossier Téléchargements.
4. Clique dans la barre d'adresse du dossier (en haut), tape  cmd  puis Entrée.
   -> Une fenêtre noire s'ouvre.
5. Tape  python robot.txt  puis Entrée.
   -> « ROBOT » et 1 / 2 / 3 : c'est bon.
   -> « n'est pas reconnu » ou « Python est introuvable » : tape  py robot.txt  puis Entrée
      (et ensuite, toujours py au lieu de python).
   -> Autre message : photo de l'écran, envoie-la.

RÈGLES PENDANT QUE LE ROBOT TOURNE
- Pour répondre : clique d'abord dans la fenêtre noire, puis tape ta réponse, puis Entrée.
- (o/n) : tape o ou n.
- « NE TOUCHEZ » : lâche clavier et souris jusqu'à la question suivante.
  Sauf « Cliquez sur l'icone du Bloc-notes » : clique dessus (en bas de l'écran), puis lâche la souris.

C. TEST (aujourd'hui) : lance le robot (étapes 3 à 5), tape 1, Entrée
6. À chaque étape : lis, puis Entrée.
7. « Adresse du portail » :
   - dans ton Chrome, ouvre l'accueil du portail ;
   - clique dans la barre d'adresse, Ctrl+C ;
   - clique dans la fenêtre noire, Ctrl+V, Entrée.
8. « Dossier robot-web » : Entrée.
   « Tapez o pour l'installer » : o, Entrée. Du texte défile (5 minutes maximum) : attends.
9. « Ouverture du navigateur du robot » : attends (30 secondes maximum).
10. Le portail s'ouvre dans une fenêtre À PART (celle du robot) :
    connecte-toi dans CETTE fenêtre si on te le demande, puis Entrée dans la fenêtre noire.
11. « Texte a chercher » : tape le nom exact d'un menu (ex : GATES), Entrée.
    « Tapez o pour ... cliquer » : o, Entrée.
    « Ca a marche ? » : o ou n, Entrée.
    Recommence avec 2 autres menus ou liens. Puis Entrée sans rien.
12. « Nom de la page 1 » :
    - dans la fenêtre du robot, va sur la page de recherche des plans (à la souris, comme d'habitude) ;
    - clique dans la fenêtre noire, tape un nom court (ex : recherche plans), Entrée ;
    - attends « page relevee ».
    Recommence pour : la liste des résultats, la fiche d'un plan, chaque onglet de la fiche.
    Puis Entrée sans rien.
13. « Entree pour fermer la fenetre du robot » : Entrée.
14. Cadre RESULTAT : prends-le en photo. Puis Entrée.
15. Ouvre Bureau > Robot > A_ENVOYER_releve.txt.
    Une vraie valeur (ex : PL-12, un nom de client) : efface ce mot seulement, enregistre.
16. Envoie-moi la photo du RESULTAT + ce fichier (ou sa photo).

D. LANCER UNE TÂCHE (quand je t'en envoie une)
17. Supprime de Téléchargements l'ancien fichier du même nom s'il y en a un.
    Enregistre le fichier tache_....txt (et la liste .csv si je t'en envoie une) dans Téléchargements.
18. Lance le robot (étapes 3 à 5), tape 3, Entrée, tape le numéro de la tâche, Entrée.
19. Une question (ex : « Numéro du plan ») : tape la valeur, Entrée.
20. « Connectez-vous si besoin » : connecte-toi dans la fenêtre du robot si on te le demande, puis Entrée.
21. « Le robot va ... » : o = oui, n = non (il passe au suivant), t = oui pour cette action pour toute la liste.
22. À la fin, « FIN : ... » : photo de cet écran, envoie-la. Puis Entrée, Entrée.
    « A VERIFIER » : va voir ce plan sur le portail.
    Le détail est dans Bureau > Robot > resultats.

E. RELEVER D'AUTRES PAGES (si je te le demande)
23. Lance le robot (étapes 3 à 5), tape 2, Entrée. Puis comme les étapes 10, 12, 15 et 16.

SI ÇA BLOQUE
- Rien ne bouge : clique sur la fenêtre noire (en bas de l'écran). Une question ? Réponds.
- « ECHEC » ou « impossible » pendant le test : continue, c'est noté dans le RESULTAT.
- « PROBLEME », message d'erreur, ou toujours rien après 1 minute : photo de tout l'écran, envoie-la.
- Changer l'adresse du portail : supprime Bureau > Robot > adresse_portail.txt, puis relance.
- Tout arrêter : Ctrl + C dans la fenêtre noire.
