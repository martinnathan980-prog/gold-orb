ROBOT VERSION 3 - CE QUE TU FAIS (15 minutes)
=============================================

SUR TON TÉLÉPHONE
1. Dans la discussion avec Claude, télécharge robot.txt (celui du message « version 3 »).
2. Envoie-le en pièce jointe à ton adresse mail du bureau.

AU BUREAU
3. Ouvre le dossier Téléchargements. Clic droit sur robot.txt -> Supprimer.
4. Ouvre le mail, enregistre robot.txt dans Téléchargements.
   -> Tu vois « robot (1).txt » : supprime les deux, recommence le 4.
5. Dans Téléchargements, clique dans la barre d'adresse (en haut), tape  cmd  , Entrée. -> fenêtre noire.
6. Tape  python robot.txt  , Entrée.
   -> « ROBOT (version 3) » : c'est bon.
   -> « version 2 » : c'est l'ancien fichier, reviens au 3.
   -> « n'est pas reconnu » ou « introuvable » : tape  py robot.txt  , Entrée.
7. Tape  1  , Entrée.
8. À chaque écran : lis, puis Entrée. Question (o/n) : tape o ou n, Entrée.
   « NE TOUCHEZ » : lâche clavier et souris jusqu'à la question suivante.
9. « Adresse du portail » : Entrée (même adresse que la dernière fois).
10. Le portail s'ouvre dans la fenêtre du robot : connecte-toi dans CETTE fenêtre si on te le demande.
    Puis fenêtre noire, Entrée.
11. « Voyez-vous des cadres rouges ? » : o ou n, Entrée.

12. « Texte a chercher » : 3 essais, un à la fois.
    a) le nom d'un menu de gauche (ex : GATES) ;
    b) le nom d'une ligne qui apparaît quand ta souris passe sur ce menu ;
    c) le nom d'une ligne qui apparaît sous un AUTRE menu de gauche.
    « le robot survole les menus » : lâche la souris (1 minute maximum).
    « Tapez o pour que le robot clique » : o, Entrée.
    « Ca a marche ? » : o ou n, Entrée.
    -> « Pas trouve » : PHOTO de l'écran (lignes « Ce que le robot voit » et « En survolant les menus »).
    Puis Entrée sans rien.

13. « Nom de la page 1 » :
    - dans la fenêtre du robot, va sur la page de recherche des plans (à la souris, comme d'habitude) ;
    - fenêtre noire : tape  recherche plans  , Entrée ;
    - lâche la souris jusqu'à « page relevee » (1 minute maximum).
    Même chose pour :
    - la liste des résultats d'une recherche      -> tape  resultats
    - la fiche d'un plan                          -> tape  fiche plan
    - chaque onglet de la fiche                   -> tape  onglet  + son nom
    - l'écran où tu duplique ou supprime un plan  -> tape  suppression  (sans rien cliquer dessus)
    Puis Entrée sans rien.
14. « Entree pour fermer » : Entrée. Cadre RESULTAT : PHOTO. Entrée.
15. Ouvre Bureau > Robot > A_ENVOYER_releve.txt. Un vrai numéro de plan, un nom de client ou de personne :
    efface ce mot seulement. Enregistre (Ctrl+S).

À M'ENVOYER
16. La photo du RESULTAT.
17. Les photos « Pas trouve » (s'il y en a).
18. Le fichier A_ENVOYER_releve.txt : envoie-le à ton mail perso, puis mets-le ici.
    (Ou des photos de son contenu, en entier.)
19. Les 3 textes tapés au 12 (si ce n'est pas secret).

NE FAIS PAS : le choix 3 (il n'y a pas encore de tâche).

SI ÇA BLOQUE : photo de tout l'écran, envoie-la. Pour arrêter : Ctrl + C dans la fenêtre noire.
