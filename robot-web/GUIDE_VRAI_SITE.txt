ROBOT WEB - METTRE A JOUR, FAIRE LA CARTE, MONTRER ET RELANCER DES TACHES
==========================================================================
(Windows, au bureau. Version 20 du robot.)

A FAIRE, DANS L'ORDRE (chaque partie est expliquee plus bas) :
   1. PARTIE A : mettre le robot a jour, version 20 (5 minutes).
   2. PARTIE E : faire la carte du portail. Vous donnez l'adresse, le robot
      explore TOUT SEUL (menus, recherches, fiches, onglets) pendant 20 a 45
      minutes, sans rien modifier. Vous n'avez rien a montrer.
   3. PARTIE G : tout rassembler en UN fichier, le relire, me l'envoyer.
   4. Ensuite, vous me dites simplement ce que vous voulez (« rechercher un
      plan et telecharger son PDF », « dupliquer le plan X »...). Je vous ecris
      la tache, vous l'ajoutez au robot (PARTIE H), vous la lancez (PARTIE C).

Ce qui change avec la version 20 :
   - LA CARTE SE FAIT TOUTE SEULE : le robot ouvre chaque menu, lance les
     recherches, ouvre une ou deux fiches de chaque sorte et leurs onglets. Il
     note chaque champ, bouton et onglet avec un repere (E5, C1, K7) : avec
     ces reperes, je peux ecrire une tache sans que vous me montriez les
     boutons un par un.
   - Il ne clique JAMAIS sur Enregistrer, Supprimer, Creer, Modifier,
     Dupliquer, Valider, Oui, OK... et coupe avant qu'il parte tout envoi qui
     ressemble a une modification.
   - LA RELANCE D'UNE TACHE NE RESTE PLUS « BLOQUEE » : avant, elle attendait
     un Entree dans la fenetre noire (« Verifiez que vous etes bien
     connecte... »). Maintenant, si vous etes deja connecte, le robot enchaine
     tout seul ; sinon un bandeau BLEU apparait en bas de SA fenetre Chrome :
     connectez-vous, il repart tout seul (ou cliquez « Continuer »).
     Vos taches deja enregistrees en profitent sans rien refaire.
   - Le robot retient l'adresse de votre portail : Entree suffit la fois
     suivante.
   - Nouveau choix 11 : ajouter une tache que je vous ai ecrite.
   - La visite guidee (vous cliquez, le robot regarde) existe toujours : au
     menu, tapez  8v  au lieu de 8.

POURQUOI LE CHROME DU ROBOT N'EST PAS VOTRE CHROME HABITUEL ?
   Chrome interdit aux robots de piloter votre Chrome a vous : c'est une
   protection de Chrome, pour que personne ne puisse prendre vos sessions.
   Le robot a donc SON Chrome, comme un collegue qui a son propre badge.
   La premiere fois, il ne vous connait pas : des pages de Chrome ou de Google
   peuvent s'afficher (« Bienvenue », « Avant d'acceder a Google »...), et le
   portail vous demande de vous connecter, comme sur un ordinateur neuf.
   Connectez-vous UNE fois : ensuite, il s'en souvient.

Dans ce guide :
   VOUS TAPEZ  = vous tapez ce texte au clavier, PUIS la touche Entree
   VOUS VOYEZ  = ce qui doit s'afficher. Si ce n'est pas ca, arretez-vous
                 et envoyez-moi ce que vous voyez a la place.
   [Entree]    = appuyez seulement sur la touche Entree, sans rien taper

Les parties :
   PARTIE A - Mettre le robot a jour                      (5 minutes, une fois)
   PARTIE B - Montrer la tache au robot                   (une fois par tache)
   PARTIE C - Relancer la tache                           (quand vous voulez)
   PARTIE D - Si ca ne marche pas
   PARTIE E - Faire la carte de mon portail (le robot seul)       (une fois)
   PARTIE F - Montrer une action au robot (facultatif)          (si je le demande)
   PARTIE G - Tout rassembler et me l'envoyer                   (apres la carte)
   PARTIE H - Ajouter une tache que je vous ai ecrite           (quand vous la recevez)


=====================================================================
 PARTIE A - METTRE A JOUR LE ROBOT (version 20)
=====================================================================
On remplace les programmes du robot par la version 20. Vos taches, vos cartes
et la connexion du Chrome du robot sont GARDEES. Votre Chrome habituel et vos
mots de passe ne sont pas touches.

A1. FERMEZ toutes les fenetres noires ouvertes, et toutes les fenetres Chrome
    ouvertes par le robot (votre Chrome habituel peut rester ouvert).

A2. Appuyez sur la touche Windows, tapez   cmd   puis Entree.
    Une fenetre noire s'ouvre.

A3. VOUS TAPEZ :
        cd /d %USERPROFILE%\robot

    VOUS VOYEZ : la ligne se termine par   C:\Users\A612990\robot>
    (avec votre identifiant a la place de A612990)
    SI « Le chemin d'acces specifie est introuvable » : le robot n'a jamais
    ete installe ici. Tapez   mkdir %USERPROFILE%\robot   puis refaites A3.

A4. On efface les anciens installeurs (pour ne pas les confondre avec le
    nouveau). VOUS TAPEZ, une ligne a la fois :
        del robot-web-installeur.txt
        del "%USERPROFILE%\Downloads\robot-web-installeur*.txt"

    VOUS VOYEZ : rien, « Fichier introuvable » ou « Impossible de trouver ... ».
    Les trois sont normaux.

A5. Dans Gmail, ouvrez mon dernier mail et telechargez la piece jointe
        robot-web-installeur.txt
    (en haut du fichier est ecrit VERSION 20)

A6. Revenez dans la fenetre noire. VOUS TAPEZ :
        move "%USERPROFILE%\Downloads\robot-web-installeur.txt" .

    (attention au point, tout au bout de la ligne : il veut dire « ici »)
    VOUS VOYEZ :   1 fichier(s) deplace(s).
    SI « Le fichier specifie est introuvable » : le telechargement n'est pas
    fini ou n'est pas alle dans Telechargements. Attendez, puis refaites A6.

A7. On verifie que c'est bien la version 20. VOUS TAPEZ :
        findstr /c:"VERSION 20" robot-web-installeur.txt

    VOUS VOYEZ une ligne qui contient :   INSTALLEUR AUTOMATIQUE - VERSION 20
    SI rien ne s'affiche : ce n'est pas le bon fichier. Refaites A4 a A6.

A8. On installe. VOUS TAPEZ (le plus simple : copier-coller, puis Entree) :
        py -c "exec(open('robot-web-installeur.txt', encoding='utf-8').read())"

    VOUS VOYEZ defiler, en 1 a 3 minutes :
        ROBOT-WEB - installeur version 20
        === 1/4  Extraction des fichiers ===
        === 2/4  Environnement Python ===
        === 3/4  Installation des bibliotheques ===
            (des lignes « Requirement already satisfied » : normal)
        === 4/4  Verification avec un faux outil web ===
        ...
         TOUT EST PRET.

    SI a la fin il n'y a pas « TOUT EST PRET » : arretez-vous et
    envoyez-moi les 10 dernieres lignes.

A9. On entre dans le dossier du robot. VOUS TAPEZ :
        cd /d %USERPROFILE%\robot\robot-web

    VOUS VOYEZ : la ligne se termine par   ...\robot\robot-web>

    La partie A est finie.


=====================================================================
 PARTIE B - MONTRER LA TACHE AU ROBOT (une seule fois par tache)
=====================================================================
B1. AVANT de toucher au robot, choisissez votre tache sur le vrai site.
    Pour la toute premiere, prenez une tache COURTE (3 a 6 gestes) et SANS
    RISQUE : pas de suppression, pas de validation definitive. Par exemple :
       - ouvrir une page de recherche, choisir un filtre, cliquer Rechercher,
         cliquer Exporter.
    Le robot refera EXACTEMENT vos gestes, avec les memes valeurs.

B2. Dans votre Chrome habituel, allez sur la page ou COMMENCE la tache.
    Cliquez une fois dans la barre d'adresse (tout en haut), puis Ctrl+C
    pour copier l'adresse. Elle commence par http:// ou https://

B3. Revenez dans la fenetre noire (partie A9 : elle doit finir par
    ...\robot\robot-web>). VOUS TAPEZ :
        robot

    VOUS VOYEZ le menu :
        ROBOT WEB   -   que voulez-vous faire ?
           1. Enregistrer une nouvelle tache (vous la montrez au robot)
           2. Lancer une tache enregistree
           ...

B4. VOUS TAPEZ :   1

B5. Il demande :   Adresse de l'outil (elle commence par http) :
    Faites un CLIC DROIT dans la fenetre noire : l'adresse copiee se colle.
    (Si rien ne se colle, essayez Ctrl+V.) Puis Entree.

B6. Il demande :   Nom de cette tache [ma tache] :
    Tapez un nom court, sans accent, qui vous parle. Par exemple :
        export contrats

B7. Il demande :
        Faut-il repeter la tache pour chaque ligne d'un fichier Excel ?
        Avec un fichier Excel ? (o/n) [n] :
    [Entree]     (= non, pas d'Excel. C'est ce qu'on veut.)

B8. VOUS VOYEZ : une fenetre Chrome s'ouvre toute seule sur votre site,
    et la fenetre noire affiche   ENREGISTREMENT EN COURS

    Ce Chrome est celui du robot : pas vos favoris, pas vos onglets.
    En haut il peut etre ecrit « Chrome est controle par un logiciel de test
    automatise » : c'est normal.

    Il ne doit y avoir QU'UN SEUL onglet, celui de votre outil. Si une page
    Google ou Chrome s'affiche quand meme (« Decouvrez... », « Nouveautes »,
    « Avant d'acceder a Google ») : ne cliquez RIEN dedans. Le robot la ferme
    en general tout seul en quelques secondes ; sinon fermez-la avec la petite
    croix de son onglet, et revenez sur l'onglet de votre outil.

B9. SI le site demande de vous connecter : connectez-vous normalement, dans
    CE Chrome-la. Le robot note l'identifiant, mais JAMAIS le mot de passe
    (il vous le demandera a chaque lancement, sans l'afficher).

B10. Faites votre tache, LENTEMENT, un geste a la fois. Attendez que chaque
     page ait fini de s'afficher avant le geste suivant.
     En bas a gauche, un bandeau rouge compte vos gestes :
         Enregistrement : 4 action(s) - cliquez pour terminer

B11. Quand la tache est finie : CLIQUEZ SUR LE BANDEAU ROUGE.
     (S'il ne reagit pas : revenez dans la fenetre noire et appuyez sur
      Entree. Ca termine aussi.)
     Le Chrome du robot se ferme.

B12. La fenetre noire affiche la liste de vos gestes, par exemple :
         == Enregistrement termine : 5 etape(s)
             1. ouvrir https://...
             2. choisir « HDK » dans Contrat
             3. cliquer sur Rechercher
             4. telecharger le fichier obtenu en cliquant sur Exporter
     Relisez : ce sont vos gestes.

B13. Puis il pose des questions. REPONSES A DONNER :

     « Etapes a retirer ... »
         [Entree]   (ou tapez le numero d'un geste en trop, puis Entree)

     « Les premieres etapes ressemblent a une connexion ... La faire une
       seule fois au debut ... ? (o/n) [o] »          (seulement si connexion)
         [Entree]

     « Dossier ou ranger les fichiers telecharges [...\robot-web\exports] »
         [Entree]                                     (seulement si export)

     « Nom du fichier, sans extension ... [export_contrats_{{horodatage}}] »
         [Entree]   ({{horodatage}} = la date et l'heure du lancement :
                     chaque lancement donne un nouveau fichier)

     « Convertir un export CSV en Excel (.xlsx) ? (o/n) [o] »
         [Entree]

     « Texte affiche par l'outil quand tout s'est bien passe ... »
         [Entree]                                     (seulement sans export)

     « Faut-il se connecter a la main au debut (SSO, mot de passe) ? (o/n) [o] »
       ou « Ajouter une pause au debut, pour verifier la connexion ... [o] »
         [Entree]   (= oui : a chaque lancement, le robot attendra que vous
                     confirmiez etre connecte. C'est le plus sur.)

     « Faire une capture d'ecran a la fin de la tache ? (o/n) [o] »
         [Entree]

B14. VOUS VOYEZ :
         Tache enregistree : C:\Users\A612990\robot\robot-web\taches\export_contrats.yaml

         Pour la relancer, maintenant ou plus tard, autant de fois que vous voulez :
            menu, choix 2, puis le numero de la tache

     Le menu revient tout seul. La tache est gardee pour toujours.


=====================================================================
 PARTIE C - RELANCER LA TACHE (quand vous voulez, autant de fois que vous voulez)
=====================================================================
C1. SI la fenetre noire est fermee (par exemple le lendemain) :
       - touche Windows, tapez   cmd   puis Entree ;
       - VOUS TAPEZ :   cd /d %USERPROFILE%\robot\robot-web
       - VOUS TAPEZ :   robot
    SI le menu est deja affiche : passez directement a C2.

C2. VOUS TAPEZ :   2

C3. VOUS VOYEZ la liste de vos taches :
        Quelle tache voulez-vous lancer ?
          1. C:\...\taches\export_contrats.yaml   (5 etape(s), rejouee en entier a chaque lancement)
    VOUS TAPEZ le numero de la tache :   1

C4. SI il demande :   Mot de passe pour « mot_de_passe » (il ne s'affiche pas) :
    tapez le mot de passe du site. RIEN NE S'AFFICHE pendant la frappe, c'est
    voulu. Puis Entree. Il n'est ecrit nulle part.

C5. Le Chrome du robot s'ouvre.
       - Si vous etes deja connecte, le robot enchaine tout seul : rien a faire.
       - Si le site demande de se connecter, un bandeau BLEU apparait en bas
         de la fenetre du robot. Connectez-vous dans CETTE fenetre : le robot
         repart tout seul des que votre outil s'affiche (ou cliquez
         « Continuer ▸ » dans le bandeau ; « Arreter » pour tout arreter).

C6. Le robot refait vos gestes tout seul. NE TOUCHEZ A RIEN, regardez.

C7. VOUS VOYEZ a la fin :
        Tache reussie. Vous pouvez la relancer quand vous voulez.
    Le menu revient.

C8. POUR LA REFAIRE : tapez encore   2   puis le numero. C'est tout.
    Autant de fois que vous voulez : jamais de « deja fait ».

C9. Si votre tache exporte un fichier, il est dans le dossier   exports   du robot.
    Pour l'ouvrir : quittez le menu (tapez 0), puis VOUS TAPEZ :
        explorer exports
    Une fenetre de l'explorateur s'ouvre avec vos fichiers, un par lancement,
    nommes avec la date et l'heure (ex. export_contrats_20260924-143005.xlsx).

C10. Pour une AUTRE tache : menu, choix 1, et refaites la PARTIE B.
     Chaque tache garde son nom ; le choix 2 les liste toutes.


=====================================================================
 PARTIE D - SI CA NE MARCHE PAS
=====================================================================
Envoyez-moi simplement :
   1. le numero de l'etape (par exemple A8, E5 ou G2) ;
   2. les 5 dernieres lignes de la fenetre noire (si une ligne contient
      « ERREUR », c'est elle la plus importante). Relisez-les avant : si
      une ligne contient un nom de plan, de projet, de personne ou une
      adresse, remplacez-le par XXX.
Pas besoin de capture d'ecran, ni du nom du site, ni de vos donnees.

Cas deja connus :
 - Le portail redemande sans cesse le mot de passe dans le Chrome du robot,
   ou Google refuse la connexion (« Ce navigateur ou cette application ne sont
   peut-etre pas securises »)
       -> menu, choix 10 : le Chrome du robot s'ouvre SANS le robot, comme un
          Chrome ordinaire. Connectez-vous au portail (et a Google s'il le
          demande), repondez Oui a « Rester connecte ? », puis FERMEZ cette
          fenetre. Ensuite, refaites la PARTIE E : la connexion est reprise.

 - Un bandeau jaune en haut du Chrome du robot (« indicateur de ligne de
   commande non pris en charge ») : c'etait la version 18. Il ne s'affiche
   plus depuis la version 19.

 - Une page Google s'ouvre, ou le robot « est sur Google » a la relance
       -> c'etait le cas en version 15. Refaites la PARTIE A avec la
          derniere version, puis la PARTIE B (l'ancienne tache contient les clics
          faits sur Google : il faut la refaire), puis la PARTIE C.
          En fin d'enregistrement, le robot dit combien d'actions faites sur
          Google ou Chrome il a ignorees : c'est normal.

 - « robot n'est pas reconnu... »
       -> vous n'etes pas dans le bon dossier. Tapez :
              cd /d %USERPROFILE%\robot\robot-web
          puis   robot

 - « Tache en ERREUR — ... delai depasse ... introuvable »
       -> la page etait plus lente que pendant l'enregistrement, ou elle a
          change. Relancez une fois (C2). Si ca recommence, envoyez-moi la
          ligne d'erreur : elle dit quel geste bloque. Une capture d'ecran du
          moment de l'erreur est rangee dans le dossier captures du robot
          (pour vous : ne me l'envoyez pas si elle montre des donnees).

 - Le robot ne demande pas le mot de passe et la connexion echoue
       -> repondez « o » a la pause (B13) et connectez-vous a la main en C5.

 - A la relance, le robot ouvre la page puis « ne fait rien »
       -> c'etait la version 19 : il attendait un Entree dans la fenetre
          noire. En version 20, il continue tout seul (bandeau bleu, C5).

 - La carte (PARTIE E) s'arrete vite, avec peu d'ecrans
       -> envoyez-moi les 5 dernieres lignes de la fenetre noire et le
          fichier de la PARTIE G : la fin du fichier (« ELEMENTS NON CLIQUES
          PAR SECURITE », « ENVOIS COUPES ») me dit ce qui l'a bloque.

 - « Le Chrome du robot est deja ouvert » ou Chrome du robot qui se ferme tout de suite
       -> un Chrome du robot est encore ouvert quelque part : fermez-le,
          puis relancez (C2).

 - Le robot rejoue mais pas exactement ce que vous vouliez
       -> recommencez la PARTIE B avec le meme nom : la nouvelle version
          s'ajoute a la liste du choix 2 (avec la date dans son nom), a cote
          de l'ancienne. Testez la nouvelle, puis supprimez l'ancienne avec
          le choix 4 du menu.


=====================================================================
 PARTIE E - FAIRE LA CARTE DE MON PORTAIL (LE ROBOT EXPLORE TOUT SEUL)
=====================================================================
Vous donnez l'adresse ; le robot fait le reste. Il ouvre chaque menu, lance
les recherches, ouvre une ou deux fiches de chaque sorte (plans, composants)
et chacun de leurs onglets, et note comment chaque ecran est construit : les
noms des champs, des boutons, des onglets, des colonnes, avec un repere (E5,
C1, K7). Jamais ce qui est ecrit dedans.
Il ne clique JAMAIS sur Enregistrer, Supprimer, Creer, Modifier, Dupliquer,
Valider, Oui, OK... Il ne remplit qu'un seul genre de champ : le champ d'une
recherche. Et tout envoi vers le portail qui ressemble a une modification est
coupe avant de partir. Les PDF ne sont pas telecharges.

E1. Fenetre noire, dans le dossier du robot (PARTIE C1), puis :
        robot
    VOUS TAPEZ :   8

E2. Il demande l'adresse de la page d'ACCUEIL du portail. Pour l'avoir : dans
    votre Chrome habituel, cliquez une fois dans la barre d'adresse, Ctrl+C.
    Puis dans la fenetre noire : clic droit (l'adresse se colle), Entree.
    (La fois suivante, il la propose entre crochets : Entree suffit.)

E3. Il demande :
        Numero ou mot a chercher (Entree = aucun) :
    Tapez un numero de plan que vous connaissez (ou un mot que vous cherchez
    souvent), Entree. Il sert seulement a essayer les recherches ; il n'est
    ecrit nulle part dans le fichier a m'envoyer. Sans numero : [Entree], le
    robot lance alors les recherches sans critere.

E4. LA PREMIERE FOIS SEULEMENT, il dit :
        C'est la PREMIERE fois que le Chrome du robot s'ouvre...
        On le fait maintenant ? (o/n) [o] :
    [Entree]. Une fenetre Chrome ORDINAIRE s'ouvre (le robot est eteint) :
       - connectez-vous au portail comme d'habitude (et a Google s'il le
         demande) ; si on vous propose « Rester connecte ? » : Oui ;
       - puis FERMEZ cette fenetre Chrome (la croix en haut a droite).
    Les fois suivantes, cette etape ne revient pas.

E5. Le Chrome du ROBOT s'ouvre (un bandeau bleu « Robot en LECTURE SEULE » en
    bas). Si le portail demande de vous connecter : connectez-vous dans CETTE
    fenetre. Affichez la page d'accueil du portail, puis revenez dans la
    fenetre noire et appuyez sur Entree. VOUS VOYEZ :
        Le robot partira de la page affichee dans sa fenetre (12 element(s) de menu).
        C'est bien votre portail, et vous etes connecte ? (o/n) [o] :
    Si c'est bien votre portail : [Entree].
    S'il affiche [n] a la fin (il a un doute : page de connexion, adresse
    differente) alors que c'est bien votre portail : tapez  o  puis Entree.

E6. Le robot explore. NE TOUCHEZ PLUS a sa fenetre (vous pouvez travailler
    dans votre Chrome habituel a cote). Il faut 20 a 45 minutes. La fenetre
    noire affiche ce qu'il voit, par exemple :
        OK E7 : « Plan ... » - 12 champ(s), 30 element(s) cliquable(s), 1 tableau(x)
    Pour l'arreter avant la fin : Entree dans la fenetre noire. Ce qui a ete
    vu est garde.
    Si le portail vous deconnecte en cours de route, le robot vous demande de
    vous reconnecter dans sa fenetre, puis continue.

E7. A la fin, VOUS VOYEZ :
        OK Exploration terminee (...).
           45 ecran(s) differents vus, ...
           Carte n° 20261003-101500 : citez ce numero et les reperes...
    et deux fichiers, dans explorations\<date> :
       - carte_PRIVEE_ne_pas_envoyer.html : tout ce qui a ete vu. Il
         reste sur votre poste : ne l'envoyez pas.
       - carte_a_partager.txt : la STRUCTURE seulement, sans vos donnees,
         avec les reperes. Par exemple :
            E5   accès : page de départ › menu « Plans » › bouton « Rechercher »
                 champs : C1 Numéro [texte] ; C2 Titre [texte]
                 boutons : K4 Rechercher → mène à E5 ; K5 Nouveau plan → non cliqué : risque
    Pour me l'envoyer : PARTIE G.

E8. Si des ecrans manquent (le robot n'a pas pu les atteindre seul) : au menu,
    tapez  8v  : c'est la visite guidee, ou vous cliquez et ou le robot
    regarde. Le bandeau vert vous guide etape par etape.

=====================================================================
 PARTIE F - MONTRER UNE ACTION AU ROBOT (FACULTATIF, SI JE LE DEMANDE)
=====================================================================
Avec la carte (PARTIE E), je peux ecrire la plupart des taches sans que vous
me les montriez. Cette partie sert si je vous le demande, ou si vous voulez
une tache tout de suite. Vous faites l'action UNE fois devant le robot. Il la refait ensuite seul, et
vous demande a chaque lancement ce qui change (le plan de depart, un titre).
Il ecrit aussi un fichier qui me decrit l'action (gestes, champs remplis ou
laisses vides, boutons), SANS aucune valeur.

ATTENTION : pendant l'enregistrement, l'action est VRAIMENT faite dans le
portail (le plan est vraiment duplique, ou vraiment supprime). Faites-la sur
un plan de test, ou supprimez justement la copie que vous venez de creer.

Le Chrome du robot est le meme que pour la carte : si vous vous y etes deja
connecte (PARTIE E), vous le restez en general.

F1. Menu, choix 1.
       Adresse de l'outil   -> la page d'ACCUEIL du portail (clic droit, Entree)
       Nom de cette tache   -> dupliquer un plan      (ou : supprimer un plan)
       Avec un fichier Excel ? -> [Entree]

F2. Dans le Chrome du robot, faites l'action normalement, LENTEMENT :
       dupliquer : cherchez le plan de depart, ouvrez-le, cliquez Dupliquer,
                   remplissez les champs comme d'habitude, Enregistrer ;
       supprimer : cherchez le plan, ouvrez-le, Supprimer, confirmez.
    Si Dupliquer ouvre un nouvel onglet : continuez simplement dedans, le
    robot suit. Puis cliquez sur le bandeau rouge.

F3. Les questions. La nouvelle, importante :
       « Vous avez ecrit, dans « Numero » : « PL-... »
         Cette valeur change-t-elle a chaque fois ? Entree = non ;
         sinon, donnez-lui un nom court »
    -> pour le numero du plan de depart : tapez   plan de depart
    -> pour un champ qui change (titre, indice...) : tapez son nom, ex. titre
    -> pour ce qui est toujours pareil : [Entree]
    Les autres questions : [Entree].

F4. VOUS VOYEZ a la fin deux fichiers, dans le dossier taches :
       dupliquer_un_plan.yaml              la tache (reste sur votre poste)
       dupliquer_un_plan_a_partager.txt    la description SANS vos donnees
    Le second sera rassemble avec la carte par le choix 9 (PARTIE G). Avec
    lui et la carte (PARTIE E), je construis les automatismes : dupliquer en
    serie depuis une liste, supprimer, lire des infos...

F5. Pour relancer : menu, choix 2, la tache. Le robot demande :
       -> Plan de depart :      (tapez le numero, Entree)
       -> Titre :               (etc.)
