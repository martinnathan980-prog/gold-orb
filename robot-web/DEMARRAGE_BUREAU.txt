ROBOT-WEB (autoweb) - DEMARRAGE AU BUREAU
=========================================

1. Decompressez le zip dans un dossier a vous, par exemple :
      C:\Users\<votre nom>\Documents\robot-web

2. Ouvrez une invite de commandes DANS ce dossier :
      dans l'explorateur, cliquez dans la barre d'adresse, tapez  cmd  puis Entree

3. Installez les bibliotheques (une seule fois) :
      py -m pip install --user -r requirements.txt
   Si "py" n'existe pas, remplacez  py  par  python  dans toutes les commandes.
   Si pip echoue (proxy), essayez :
      py -m pip install --user --trusted-host pypi.org --trusted-host files.pythonhosted.org -r requirements.txt

4. Testez : le robot ouvre votre Edge sur un faux outil et remplit 4 lignes d'Excel
      py -m autoweb demo
   Resultat attendu a la fin :  "3 OK, 1 ERREUR"  puis  "votre poste est pret".
   (l'erreur est volontaire : une ligne sans numero de plan)

5. Si le navigateur ne se lance pas ("Aucun navigateur n'a pu etre lance") :
      py -m playwright install chromium
   puis relancez  py -m autoweb demo
   Si ca echoue encore, copiez le message d'erreur et le fichier demo\journal\autoweb-*.log
   et envoyez-les a Claude.

6. Votre premier vrai outil, SANS rien envoyer a l'exterieur : l'ASSISTANT construit
   le scenario sur votre poste, par questions/reponses.
   a) Preparez votre Excel de suivi (une ligne par element, les noms de colonnes en ligne 1),
      ou creez-en un vide :   py -m autoweb initialiser mon_outil --colonnes "Numero plan,Titre,Type"
   b) Lancez l'assistant sur l'ecran a automatiser :
      py -m autoweb assistant https://adresse-de-votre-outil --canal chrome --excel mon_outil\suivi.xlsx --nom "nouveau plan"
      Chrome s'ouvre : connectez-vous, affichez le formulaire vide, revenez dans la console, Entree.
      L'assistant liste chaque champ de l'ecran et vous demande quelle colonne Excel le remplit
      (il propose la plus probable : Entree pour accepter, 0 pour ignorer, v pour une valeur fixe),
      puis quel bouton enregistre, quel texte confirme le succes, etc.
   c) Il ecrit mon_outil\nouveau_plan.yaml. Testez-le :
      py -m autoweb verifier mon_outil\nouveau_plan.yaml
      py -m autoweb simuler  mon_outil\nouveau_plan.yaml
      py -m autoweb lancer   mon_outil\nouveau_plan.yaml --limite 1
      (le scenario contient une pause avant le clic final : vous verifiez a l'ecran)
   d) Pour ajuster a la main : ouvrez le .yaml avec le Bloc-notes, l'aide-memoire des actions est
      dans README.md. Le dossier releves\<date>-<nom>\champs.txt liste tous les selecteurs.

   Le dossier releves\ et vos fichiers restent sur votre poste. Si vous demandez de l'aide a
   Claude, decrivez l'ecran avec des noms neutres (champ 1, liste 2, bouton Enregistrer) et
   copiez seulement la ligne d'erreur de la console.

7. Vos sessions (SSO) : pour que le robot travaille dans un Chrome ou vous etes deja
   connecte, lancez chrome_debug.bat, connectez-vous, et mettez dans le scenario :
      navigateur:
        attacher: 9222

Mode d'emploi complet : README.md (ouvrable avec le Bloc-notes).
